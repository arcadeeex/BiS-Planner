# BisEquip module data files

This directory stores generated static Lua modules used by `Core/ModuleData.lua`.

- One file per section (`PVP.lua`, `WotLKRaid.lua`, etc.).
- Every file is generated by `scripts/extract_atlasloot.py`.
- Runtime logic should only do lightweight lookups over these prebuilt entries.

Entry format:

```lua
{ slot = 1, item = 12345, source = "SomeTable", difficulty = "10N", category = "PvP награды", instance = "A7", sourceLabel = "Воин", classLabel = "Воин" }
```
